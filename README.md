# programmers-study
코딩테스트 대비 프로그래머스 스터디

## 공부 목표

쉬운 프로그래머스 문제로 Python 3 문법과 구현 감각을 회복합니다.
기간은 2026-09-24~2026-10-21이며, 하루 20~30분, 주 5일 연습·수요일 복습·일요일 휴식을 기본으로 합니다.
전공 공부 직후 5분 문법 회상 → 15분 풀이 → 5분 피드백을 기록합니다.
바쁜 날에는 5분 최소 루틴만 하고, 놓친 분량은 다음 학습일에 이어갑니다.

[노션 4주 루틴](https://app.notion.com/p/3e51804f49dc81e39182f7d36afd6daa)과
[일별 풀이·피드백 기록](https://app.notion.com/p/3e51804f49dc81c1a137db1fb62aecd2)을 기준으로 구성했습니다.
상세 개념은 노션에, 실행 가능한 코드와 핵심 피드백은 GitHub에 남깁니다.
노션의 언어는 미정으로 되어 있지만, 이 저장소는 현재 학습 언어인 Python으로 구성합니다.

## 폴더 구조

```text
programmers-study/
├── README.md
├── .gitignore
├── week01/  # 09-24~09-30: 기본 문법
├── week02/  # 10-01~10-07: 배열·문자열
├── week03/  # 10-08~10-14: 정렬·해시·스택
└── week04/  # 10-15~10-21: 완전탐색·해시
    └── YYYY-MM-DD_문제명/
        ├── README.md
        └── solution.py  # 풀이·이어 풀기 날에만 존재
```

문제명의 공백은 폴더에서 밑줄로 표시합니다. 복습일·휴식일은 README만 둡니다.
수요일 복습에서 코드를 작성할 때는 선택한 문제의 solution.py를 사용하고 복습 기록에 경로를 적습니다.
날짜는 예정일입니다. 실제 학습일·시간·풀이 상태·정답 제출 여부는 직접 기록합니다.
노션 일정 체크는 정답 여부가 아니므로 GitHub의 학습 결과로 자동 복사하지 않았습니다.
이어 풀기 날에는 해당 날짜의 빈 함수 틀에서 이어 작성하거나 다시 풉니다.

## VS Code 실행·디버깅

1. Python 3와 VS Code의 Microsoft Python·Python Debugger 확장을 준비하고 저장소 폴더를 엽니다.
2. 명령 팔레트에서 `Python: Select Interpreter`로 Python 3 인터프리터를 선택합니다.
3. 날짜별 `solution.py`를 열어 `solution` 함수 안의 `raise NotImplementedError(...)`를 자신의 풀이로 교체합니다. 함수는 주어진 매개변수를 처리해 값을 `return`합니다.
4. 우측 상단 실행 버튼의 `Run Python File in Terminal` 또는 아래 명령으로 실행합니다. 경로는 저장소 루트 기준입니다.

```powershell
python "./week01/2026-09-24_두_수의_합_구하기/solution.py"
```

Windows에서 `python` 명령을 사용할 수 없고 Python Launcher가 설치되어 있다면 `py`로 실행합니다.
직접 실행용 예제는 `if __name__ == "__main__":` 아래에만 있습니다.
처음 실행하면 미구현 안내가 나오며, 풀이 작성 후에는 공식 예제의 결과와 기대값을 비교합니다.
예제 통과와 프로그래머스 정답 제출 결과는 별도로 기록합니다.
함수 매개변수와 예제는 각 파일에 적힌 공식 문제 페이지에서 확인했습니다.

디버깅은 함수 안의 확인할 줄 왼쪽을 클릭해 중단점을 놓고 F5를 누릅니다.
구성 선택이 나오면 `Python Debugger` → `Python File`을 선택합니다.
F10으로 한 줄씩 실행하고 변수 값을 확인합니다. 최초 틀의 예외 줄은 풀이 작성 후 교체합니다.
제출할 때는 `solution` 함수와 필요한 import를 사용합니다.

## 커밋·푸시

저장소 루트에서 변경 내용을 확인한 뒤 실행합니다. 커밋과 푸시는 직접 진행합니다.

```powershell
git status
git diff
git add README.md .gitignore week01 week02 week03 week04
git diff --cached
git commit -m "docs: 파이썬 4주 학습 구조와 기록 양식 추가"
git push origin main
```

새 파일 내용은 `git diff --cached`에서 확인할 수 있습니다.
일상 학습에서는 `git add` 뒤에 해당 날짜 폴더 경로를 지정하고 문제명에 맞는 커밋 메시지를 적습니다.
